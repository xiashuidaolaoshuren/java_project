# Day capacity is derived, not typed in

Generate accepts only `planDate`. Placeable minutes are the work window minus fixed breaks, overlapping commitments, and the trailing buffer. A typed `availableMinutes` would disagree with the clock (a 60-minute budget inside a 09:00–18:00 rail) and keep the model doing arithmetic 1.2.0 exists to remove. Optional per-day window overrides were rejected: change preferences, or accept the saved window.
